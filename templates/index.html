Templates LaTeX

Trois templates LaTeX prêts à l'emploi. Les archives zip téléchargeables contiennent un fichier latex de démonstration (et sa version pdf), la classe LaTeX et les images nécessaires.

Templates disponibles

Chaque modèle garde un contenu volontairement minimal : le main.tex sert de présentation pour voir les commandes, les figures, les tableaux, les liens et les blocs de code.

Template ECL

Le modèle le plus complet, avec sommaire, bibliographie, encadrés, figures, tableaux, équations, code et liens.

Basé sur le template Centrale Lyon de Riad Attou, sous licence CC BY 4.0.

Télécharger le ZIP

Template simple ECL

Une version plus simple avec un style légèrement différent. Elle comprend tout de même une page de garde, sections, figures, tableaux, équations et code.

Fortement inspiré du template Rapport Centrale Lyon de Pierre Antoine B., sous licence CC BY 4.0.

Télécharger le ZIP

Template ECL Diapos

Similaire aux précents mais destiné à la création de diapositives.

Basé sur le Rapport Centrale Lyon 2024 de Paul Hadjian, sous licence CC BY 4.0.

Télécharger le ZIP

Utilisation

Téléchargez l'archive, décompressez-la, puis ouvrez main.tex dans votre éditeur LaTeX ou importez le dossier dans Overleaf/Prism/autre.
